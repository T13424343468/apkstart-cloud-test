# TaoZip（道压缩）安卓版 · 安装与使用说明

> 版本 2.0（安卓 arm64）· 安装包：TaoZip安卓版2.0.apk · 界面语言：中文

## 一、安装

1. 把 `TaoZip安卓版2.0.apk` 传到手机（微信文件传输助手 / 数据线 / 网盘均可）。
2. 在手机上点开安装包。首次安装系统会提示"未知来源应用"，选择"允许"或到 设置 → 应用 → 特殊权限 中开启即可。
3. 打开 TaoZip，会弹出"所有文件访问"授权页 → 找到 TaoZip → 打开"允许访问所有文件"→ 返回。
   （这一步必须有，否则无法浏览和管理手机文件。）

要求：Android 8.0 及以上（arm64 机型，2018 年以后的手机基本都满足）。

## 二、2.0 新界面

- **三个页签**：文件 / 分类 / 压缩包。文件页管目录和操作；分类页按图片、视频、音频、文档、安装包等类型直达；压缩包页汇总手机里所有压缩文件。
- **三套主题，即点即换**：设置里在水墨（默认）、天灰、墨夜之间一键切换，全局立即生效，配色经过对比度校验，深色环境也看得清。
- **空态不迷路**：每个列表在没内容时都有明确提示，告诉你这里会出现什么。
- **弹窗统一**：确认、进度、输入全部用同一套风格的对话框。
- **图标全自绘**：文件类型、操作按钮图标均为矢量自绘，任何主题下都清晰。

## 三、功能

**文件管理（文件页）**
- 浏览手机全部目录和文件（含内置存储、SD 卡）
- 多选（长按进入）：压缩 / 删除 / 复制 / 移动（粘贴到目标目录）
- 新建文件夹、重命名、查看详情
- 分卷包（.001/.002…）：点第一个卷可直接合并还原成完整文件

**压缩**
- 多选后点"压缩"：支持 zip（可加密码、设置分卷大小、1-9 级压缩）、tar、tar.gz
- 输出在当前目录

**解压**
- 点开任意压缩包：查看内部文件列表、大小、时间
- 支持 zip / 7z / rar（仅解压）/ tar / tar.gz / gz / bz2 / xz
- 加密包：点"密码"输入后重新读取
- 旧版中文包乱码：点"编码"切换 UTF-8 / GBK
- "解压到…"默认建议同名文件夹（智能解压），可自行修改路径
- "测试完整性"逐文件校验，能报出损坏条目

## 四、已知限制

- 7z 和 rar 因授权限制，只能解压、不能创建
- 暂不支持打开压缩包内的单个文件（需先解压）
- 安装包为固定签名，后续更新可直接覆盖安装

## 五、源码包

内含：核心引擎（TaoZip.Model / DAL / BLL）、安卓界面（TaoZip.UI.Android）、图标生成脚本与图标资源。
构建命令（需 .NET 8 SDK + Android workload + JDK17 + Android SDK）：

```
dotnet build ui/TaoZip.UI.Android -c Release
```

产物在 `bin/Release/net8.0-android/android-arm64/com.taozip.app-Signed.apk`。
