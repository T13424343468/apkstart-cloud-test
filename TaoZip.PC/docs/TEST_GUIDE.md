# TaoZip PC 版测试说明

## 自动化测试（四层组织，任何平台）

测试按 单元 / 集成 / 系统 / 暴力四层组织，每层含功能性与健壮性用例（异常路径、边界、故障注入），交付前四层必须全部通过：

```
cd TaoZip.PC
dotnet test tests/TaoZip.Core.Tests -c Release
```

预期：**Passed! 29 / Failed! 0**，层次分布：

- **单元层 14**（`Unit/`）：历史记录读写/上限截断/损坏文件兜底自愈、解压目标目录建议（去后缀/序号/纯点名）、条目列表含 tar 包；主题设置存取（水墨默认/三主题往返/越界收敛/损坏回退）。
- **集成层 6**（`Integration/ArchiveRoundTripTests.cs`）：zip 与 tar.gz 中文往返、子目录与空目录保留、完好包统计、进度回调 0-100 有限且不回跳。
- **系统层 4**（`System/E2EAndDeliveryTests.cs`）：多级中文目录树端到端（删源后逐字节校验）、损坏/垃圾/空文件故障注入、路径穿越拒绝，以及**交付链完整性检查**——build.bat 必须 GBK+CRLF、含非破坏性 out.new 时序；package.ps1 必须带版本行、Codepage=936、离线 WiX 工具在位。
- **暴力层 5**（`Brute/StressTests.cs`，固定必跑）：攻击面（路径穿越/Windows 保留名/控制字符/超长名全部拦截且不越界落盘）、300 条模糊输入过全部解析入口不崩、12MB 级多文件大数据往返 SHA256 字节一致、8 线程并发压解无死锁无串包、失败/中止路径不残留半截压缩包。

## 一键构建（Windows 实机）

```
双击或命令行运行 build.bat
```

- 第 1–4 步：还原 → 构建 → 自包含发布 → 整理绿色版到 out.new 临时目录。
- 第 5 步：离线生成 MSI。**非破坏性设计**：全部成功后才把 out.new 整体替换 out；任一步失败，旧的 out（含上一版 msi）原样保留，不再出现"打包失败后产物点没了"。
- 失败时看 out.new\msi-build.log，把报错和日志一起发开发者。

## Windows 实机验收清单

1. 拖入 zip/7z/rar/tar.gz → 条目列表正确显示（中文名不乱码）
2. 智能解压：单根包解出根目录本身；散文件包自动建同名文件夹
3. 完整性测试：正常包出统计，手工破坏的包明确报错
4. 压缩文件夹 → zip，解压后目录结构与原一致
5. 拖入多个普通文件 → 弹保存框直接打包
6. 历史记录：操作后立即可见；双击条目资源管理器定位
7. 解压进度窗：预计剩余时间稳定不跳变；大文件中途不冻结；失败后不再误报
8. 产物核验：out\TaoZip-1.0-x64.msi 可安装/卸载（拷到无 .NET 的机器上，msi 安装后同样可运行）；
   发布目录（publish 文件夹）里的 TaoZip.exe 免安装可直接运行（绿色版不再单独拷入 out）
