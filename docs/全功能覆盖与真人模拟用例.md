# TaoZip 全功能覆盖与真人模拟用例（2026-11-07）

生成规则（11-06 23:38–23:58 标准）：覆盖本产品**全部功能**；每条用例 = 真人操作流（PC 按真实鼠标坐标点击路径，安卓按真人触控坐标）+ **功能结果准确性核对**；维度按万链五维穷举：操作对象 × 操作方式 × 参数形态 × 顺序组合 × 异常边界/环境状态。

## 一、全功能清单（对照源）

来源：TaoZip.PC/README.md、docs/版本沿革.md（v91 及更早）、ZipGo/TaoZip-安卓版-说明.md、.github/workflows/ci.yml。

| # | 功能 | 说明/边界 |
| --- | --- | --- |
| F1 | 压缩 zip | 单文件/多文件/文件夹/嵌套 |
| F2 | 压缩 tar.gz | 同上 |
| F3 | 解压 zip / 7z / rar / tar / gz / bz2 / xz | rar、7z 仅解压不支持创建 |
| F4 | 完整性测试 | 对包做完整性检查 |
| F5 | 智能解压 | 单根文件夹直接解出；否则建同名文件夹防散落 |
| F6 | 历史记录 | 主窗+右键、压缩+解压、成功失败都记；Sources 来源列表可搜索；实时自动刷新 |
| F7 | 清理全部 / 全部删除 | 前者只清记录；后者可勾选连删本地压缩包，后台逐个删+完成统计报告 |
| F8 | 拖拽 | 拖文件压缩；拖包打开/解压 |
| F9 | 右键菜单 | 资源管理器右键压缩/解压，关联+图标，安装页勾选，启动自愈修复残留 |
| F10 | 主题三象切换 | 水墨/天青/墨夜，三窗一体+标题栏钉色，theme.log 自证 |
| F11 | 托盘 | 后台任务转托盘、点击唤起、explorer 重启自动补挂 |
| F12 | 任务中心 | 排队/暂停/恢复/取消；排序、筛选、搜索 |
| F13 | MSI 安装器 | 三步安装、默认 D:\Program Files\TaoZip、快捷方式、关联格式勾选、卸载清理、先卸后装 |
| F14 | 绿色版 | publish 目录 TaoZip.exe 免安装运行 |
| F15 | 数据目录 | D:\TaoZipData\TaoZip，旧数据自动迁移 |
| F16 | 安卓 ZipGo | 启动、浏览内部存储、压缩/解压、任务中心、排序、搜索 |

已知边界（文档已声明，不计缺口）：rar/7z 不支持创建；zip 加密暂不支持；分卷暂不支持；无文件管理器。

## 二、真人模拟用例（五维矩阵）

执行平台：PC 用例跑 Windows 真机/云端 Windows（真实鼠标路径）；安卓用例跑云端模拟器（真实触控坐标）。绿红都报，截图/录屏留证。

### Z1 压缩保真（准确性重点）
- 对象×参数形态：单文件 / 多文件 / 空文件夹 / 嵌套目录 / 中文+空格+特殊字符名 / 超长路径 / 0 字节文件 / 大文件（≥100MB）/ 罕见扩展名混选；格式 zip 与 tar.gz 各跑一轮
- 真人操作流：拖文件入主窗（或右键菜单）→ 选格式 → 真实坐标点击「开始」→ 等完成
- 准确性核对：产物存在；包内内容逐字节哈希与源一致；历史记录新增含产物路径与来源
- 异常边界：目标盘磁盘满、源文件压缩中途被删、同名产物已存在 → 报错准确、进程不崩、历史记失败条目

### Z2 解压保真（准确性重点）
- 对象×格式：七种支持格式各一 + 嵌套目录包 / 含中文名包 / 超长路径包
- 操作流：右键压缩包 → 真实点击「解压」→ 等完成
- 智能解压核对：单根包解出该文件夹本体；多根包解出同名文件夹；重复解压幂等不翻倍
- 异常边界：损坏包（截断/改字节）、密码包（明确提示不支持）、磁盘满 → 报错准确、无半成品残留或残留如实记录

### Z3 完整性测试
- 对象：正常包 / 损坏包 / 空包
- 操作流：选中包 → 真实点击完整性测试 → 读结果
- 核对：正常包报通过；损坏包报出具体失败且不崩溃

### Z4 历史记录与实时刷新
- 顺序组合：主窗压缩 → 右键小窗解压 → 不手动刷新，核对主窗历史页自动出现新条目
- 参数形态：搜索产物名 / 来源路径关键词；空态显示提示
- 核对：每条含时间、动作、结果、产物与来源；失败操作也入史；跨进程写入后自动重载

### Z5 清理全部 / 全部删除
- 「清理全部」：只清记录，本地文件逐个核对仍在
- 「全部删除」勾选删文件：后台逐个删 → 文件确删 + 完成统计条数与实际一致；不勾选时文件保留

### Z6 拖拽路径
- 拖文件夹入主窗 → 出压缩入口；拖 zip 入主窗 → 出打开/解压入口；拖入不相关格式 → 明确报错不误处理

### Z7 右键菜单关联
- 装机后核对：压缩包/文件夹/多选文件的右键项与图标齐全；点击后小窗内容正常、主题随象
- 升级路径：旧版残留先清、新版生效（自愈修复被真机验证过）

### Z8 主题三象切换
- 顺序组合：水墨→天青→墨夜→水墨（含两个浅色象互切路径）
- 核对：三窗同步换色、墨夜标题栏按钮可辨、theme.log 每次切换留痕

### Z9 托盘
- 后台任务最小化 → 托盘在；点击唤起；重启 explorer → 自动补挂
- 标注：真机人工验证点，云端模拟器盖不到 explorer 重启，列入补测范围

### Z10 任务中心与列表操作（安卓触控为主，PC 同口径）
- 多任务：连发 3 个任务看排队/并发；暂停→恢复→取消各一遍，核对状态与实际文件产出一致
- 排序×筛选×搜索组合切换：结果稳定
- 真人路径：全部坐标取自当次界面树解析；**搜索框等禁止硬编码坐标（如 tap 540 320），必须动态取 bounds**；点击排序菜单后需断言列表顺序实际变化（仅截图不算核对）

### Z11 安装、卸载与数据迁移
- MSI：三步安装 → 默认 D 盘路径正确 → 快捷方式齐全 → 卸载干净（右键关联清干净、清理项移除）
- 旧数据迁移：模拟旧版本数据 → 升级装 → 历史记录不丢
- 绿色版：同机免安装运行，与安装版数据互不干扰

### Z12 安卓 ZipGo 启动与浏览
- 冷启动 → 进程存活；进入内部存储 → 浏览目录 → 选包解压 → 核对解出内容与包内一致
